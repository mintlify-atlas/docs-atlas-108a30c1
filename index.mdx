Metrica Bienes Raices is a full-stack real estate management platform built with React 19 and TypeScript. It provides role-specific dashboards for Administrators, Agents, and Clients — covering property listings, CRM lead tracking, calendar scheduling, analytics reports, and multi-format exports.

## Get Started

<Steps>
  <Step title="Set up the environment">
    Clone the repository and configure your `.env` file with the backend API URL and any required credentials. See [Environment Setup](/environment-setup) for all required variables.
  </Step>
  <Step title="Install dependencies and run">
    Install packages and start the development server. The app uses CRACO for Webpack customization on top of Create React App.
  </Step>
  <Step title="Log in with a role">
    Use the `/iniciar-sesion` login page to authenticate as an Administrador, Agente, or Cliente. Each role is routed to its own dashboard automatically.
  </Step>
  <Step title="Explore the dashboards">
    Navigate using the role-aware sidebar. Administrators can manage users, properties, leads, calendars, and reports. Agents handle their assigned properties and cases. Clients browse available listings and submit requests.
  </Step>
</Steps>

<Note>
  The frontend communicates with an external REST API via the `REACT_APP_API_URL` environment variable. Make sure the backend is running and reachable before starting the development server.
</Note>
